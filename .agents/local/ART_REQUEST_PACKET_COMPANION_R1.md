# ART_REQUEST_PACKET — GOAL 陪伴 (R1)

目的：为 autonomous-fleet Pack 生成正式原创车辆宠物母图，替换现有程序化占位美术。
本包可直接粘贴到具备图像生成能力的 ChatGPT 中使用。运行与构建过程不调用图像模型；
母图返回后由本地确定性管线（scripts/generate-pack-assets.mjs，sharp）完成导出。

## 交付物（Owner Gate）

透明背景 PNG 母图，每张 ≥1024×1024，侧视（朝右），单一主体居中，
边缘留 ≥5% 透明边距。需要 4 张：

| 文件 | 阶段 | 画面要求 |
|---|---|---|
| master-l1 | L1 首航路测 | 一辆可爱的小车，主驾坐着人类驾驶员，副驾空，车顶有小标志物；车后跟随一辆小的保护车（可同框或单独一张 master-guard） |
| master-l2 | L2 独立巡航 | 同一角色，主驾仍有人，副驾空，无保护车；姿态更自信（如微抬悬挂/亮灯） |
| master-l3 | L3 安全员随行 | 主驾空，副驾坐着安全员角色，保护车回归 |
| master-l4 | L4+ | 主驾副驾均空（无人驾驶），车辆本身更有"成长感"（更大/更亮/更多细节），保护车在场 |

## 角色一致性要求（硬性）

- 同一辆"车宠物"贯穿 4 张：相同车型比例、相同配色、相同"眼睛/表情"元素；
- 风格：可爱、圆润、现代插画风（扁平或轻渐变均可），禁止写实照片风；
- 状态辨识目标：在 112px 显示尺寸下，仅凭形象即可区分——
  主驾有人 / 主驾空副驾有安全员 / 有无保护车 / 车辆成熟度差异；
- 每张主体（不含保护车）应独立可裁剪：若保护车与主体同框，
  请保证主体与保护车之间有明显透明间隔，便于拆分；
- 背景必须全透明，不要地面阴影以外的场景元素。

## 不需要

- 不需要背景图、UI、文字、水印；
- 不需要 L5–L12 母图（本期沿用 l4 资产 + 场景表达规模）。

## 返回后流程

1. Owner 选定母图 → 放入 .assets-check-tmp/ 或指定目录；
2. 本地拆分/缩放为 sprite-subject-pod--l1..l4 的 PNG+WebP（保持现有 asset ID 与 manifest 不变）；
3. node scripts/generate-pack-assets.mjs --check 验证确定性；
4. 独立 DSH 预览 112px 盲测 → Owner 最终确认。
