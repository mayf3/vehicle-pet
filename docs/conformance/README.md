# Conformance

This directory is the persistent location for conformance records for `mayf3/vehicle-pet`.

Conformance reports evaluate an exact implementation Head against accepted governing Contracts and Acceptance items. They do not change Spec lifecycle and cannot convert a proposed Spec into active authority. Future conformance evidence must also be recorded in the corresponding implementation PR.

Use `.agents/templates/CONFORMANCE_RECORD_TEMPLATE.md` for future records. No product implementation or conformance claim exists at the current empty seed.
