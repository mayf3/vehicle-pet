# L6–L12 数量区分改版

L1–L5 用户已认可，按字节复制上一版 PNG。仅重做 L6–L12 的视觉候选，沿用旧版一人监管 3、10、100、1,000、10,000、100,000、1,000,000 辆的等级含义。

每级用独立规模轮廓加大数字：三车小队、十车阵列、百车密集车队、千车城市、万车多城区域、十万车多区域、百万车全球。高等级城市与车辆为示意性数量，不宣称图上逐辆画出全部实际监管规模。数字由本地字体精确排版，避免生成图文字错误；没有数值底板或整块背景。

生成方式：内置 image_gen，每级独立调用，沿用用户确认的蓝白 Pony.ai 车型。PNG 原生 alpha 保留；必要时按用户已授予的本地处理授权去背景。最终 PNG、lossless WebP 和 480 像素版本均有透明通道。prompts.json 保存提示词和生成文件来源，quality.json 保存输出检查和哈希。

本目录是素材预览，未变更运行中插件。打开 index.html 可切换深浅页面与悬浮尺寸。
