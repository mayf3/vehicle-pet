# 原版等级 · Pony.ai 视觉候选

用户在本轮明确要求恢复旧版等级出图。依据 CONFIGURABLE_PET_ENGINE_V1 §11.1 的人员位置、保护车有无和远程监管规模；沿用已确认蓝白车型、中央单雷达与纯文字 Pony.ai。

L1/L2 主驾有人、副驾无人，分别有/无保护车。L3/L4 主驾无人、副驾有安全员，分别有/无保护车。L5 车内无人、无保护车，一人监管一车。L6–L12 一人分别监管 3、10、100、1,000、10,000、100,000、1,000,000 辆无人车。

高等级只画代表性车队节点，不字面渲染海量车辆。监管人员在车外单独表现；不是驾驶员，也不表达远程驾驶。实际规模由预览页文字明确标注。

执行方式：内置 image_gen 每级独立调用，提示词及原文件路径见 prompts.json。对原生 alpha 予以保留；其他图依据用户明确授权用本地 Python/Pillow/scipy 抠除轮廓外背景。PNG 和 lossless WebP 保存真实透明通道。quality.json 为文件检查记录。

此目录为用户要求的独立视觉预览，未改动运行中插件及冻结 packVersion。旧版等级与当前 V2 的全无人/全级跟班定义有差异；生产接入需同步后续权威、叙事、素材版本及透明容器，不能直接覆盖旧版本资产。

打开 index.html 可切换浅/深色宿主背景与小尺寸预览。每张小车自身无背景板、遮罩或阴影滤镜。
