# Investigations

This directory is the persistent location for bounded investigation records and evidence used by `mayf3/vehicle-pet` governance.

Investigations are descriptive, not normative. They may support or contradict Claims in a governing Spec, but they do not become Product Direction, Architecture, implementation authorization, or acceptance authority by themselves. A DeepSeek Harness prototype, if referenced later, is investigation evidence only and is not authority in this repository.

Use `.agents/templates/INVESTIGATION_RECORD_TEMPLATE.md` for future records. Bind each record to exact subject, revision, environment, timestamp, method, result, limits, and provenance.
